# StyleKit · 噪声边缘组件生成器

网页样式组件生成器。第一个效果 **波浪边缘块**：纯色块，边缘由噪声实时生成、连续形变。
全窗口画布，参数走跟随图形的气泡，选中图形直接拖把手缩放/旋转。

```
stylekit/
├─ index.html            工作台
├─ css/studio.css        HUD 样式（暖陶土 + 青蓝 + 奶油，参考 feralui.dev）
├─ src/noise.js          seeded 3D simplex noise
├─ src/wavy.js           ★ 效果本体：周长参数化 + 周期噪声位移 + 参数 schema + 预设
├─ src/wavy-element.js   <wavy-edge> 自定义元素
├─ src/exporters.js      SVG / CSS / 独立 HTML（支持旋转）
├─ src/studio.js         画布、气泡、图层、把手、导出
├─ dist/wavy-edge.js     分发版（noise + wavy + element 拼接）
└─ tools/                bundle / 截图验收 / 导出验收 / 数值检查（在 apps/stylekit/ 下执行）
```

## 跑起来

```powershell
cd stylekit
py -3 -m http.server 8791 --bind 127.0.0.1
# 打开 http://127.0.0.1:8791/
```

## 界面

- **画布铺满整个窗口**，没有侧栏。图形用窗口坐标定位，窗口缩放时不会跑位。
- **参数气泡**：选中哪个图形，气泡就贴在它旁边（右侧放不下自动翻到左侧）。
  默认只展开 4 个核心项：**振幅 / 波数 / 噪声模式 / 填充色**；
  其余同类参数折成 5 个可展开组：形状与尺寸、噪声细节、动画、描边、投影。
  气泡头可拖动，双击回到跟随图形。
- **创建元素**和**图层管理**是两件独立的事，各占一块：

  | 区域 | 位置 | 职责 |
  |---|---|---|
  | 创建工具条 | 顶部居中 | 「新建」+ 5 个形状图标（点哪个就新建一个该形状的元素）+ `⧉` 复制选中。新元素继承当前颜色，落点自动错开 |
  | 图层面板 | 右上 | 只管已有元素：选中、调层级（↑↓）、复制（⧉）、删除（✕）、看坐标 |

  这样「造东西」和「整理东西」不挤在一个面板里；图层面板本身也变短了，只留列表。
- **点画布空白处**（或按 `Esc`）会同时藏掉选框、八个把手和参数气泡，画布立刻变干净，方便单独观察
  形变动画；点任一图形即恢复。
- **全站零描边**：所有 UI 元素都不画 `border`（连浏览器默认的 `button/select/input` 边框也用一条
  `button, select, input, textarea, fieldset { border: 0; background: none; }` 重置掉）。
  强调一律用**面**表达颜色，不用线：

  | 状态 | 做法 |
  |---|---|
  | 选中的形状图标 / 图层按钮 / HTML 按钮 / 切页选中 | `background: var(--clay)` + 深色字 |
  | 选中的图层行 | 陶土半透明**实色底** `rgba(201,112,74,.28)` |
  | 展开的折叠组标题 | 青色半透明实色底 `rgba(139,209,216,.1)` |
  | 背景选择器的当前项 | **保留描边环**（`inset box-shadow` 2px 青色）—— 这是唯一例外，圆点语义不明 |
  | 悬停 | 只提亮底色，不改任何边框 |

  副作用处理：`select { appearance: none }` 会把原生下拉箭头也去掉，所以用两个 45°/135° 渐变
  画了一个纯色三角补回来（`select.full`），`.mini-select` 同理。唯一保留的 `border` 是折叠箭头
  `.chev`（用 `border-left/top/bottom` 拼三角形，是形状不是描边）。

- **折叠箭头在右侧**（`right: 2px`，距标题右缘 2px），标题左侧不再有东西顶到面板边缘；
  标题整体左缘仍与参数标签同列（198px）。

- **预设 chips 用流式布局**：色点从「绝对定位到左侧沟槽」改为**chip 内部 flex 项**（`gap: 6px`），
  所以不会压到前一个 chip 身上；`padding: 4px 10px` 全站统一，`gap: 6px` 自动换行，
  首列与参数标签同一条竖线（198px），最低一个 chip 距气泡底还有 14px，不会被裁。

- 浮层用 **iOS 连续曲率圆角**，但分两类，混用会崩（这是踩过的坑）：

  | 元素 | `border-radius` | `corner-shape` | 原因 |
  |---|---|---|---|
  | 卡片/气泡/输入框 | 16–18px | `superellipse(1.6)` | 连续曲率，咬入量 ≈ 同半径圆角的 71%，接近 Figma `cornerSmoothing 60%` |
  | 顶栏 / 按钮 / chip / 导出条 | `999px` | `round` | 半径被夹到高度一半后，超椭圆会把两端从半圆压成直角，看着就是「圆角没了」 |

  实测（r=24，量对角线咬入像素）：`round` 7.0px · `superellipse(1.4)` 5.5 · **`superellipse(1.6)` 5.0** ·
  `superellipse(1.8)` 3.5 · `squircle` 3.5 · `superellipse(4)` 1.0。所以 `superellipse(4)` 和 `squircle`
  在中文 UI 常用的小半径上都会显得「方了」，选 1.6 才既有 iOS 的味道又不丢圆角。
  不支持的浏览器自动退回普通 `border-radius`。

- 阴影压得很淡（`0 16px 44px -14px rgba(0,0,0,.42)` + `0 2px 10px rgba(0,0,0,.14)`），
  靠背景模糊而不是黑边分层。
- **导出**是左下角一排悬浮按钮，不占画布、不弹代码窗。`HTML` 单击 = 下载单文件组件（`Shift+单击` = 复制代码，
  两个动作并到一个按钮上）；`CSS` 复制选中变体的 clip-path 版；`SVG` / `JSON` 复制；
  `WebM` 把动画录下来。按钮点完会短暂变成「已复制 / 已存」。
- 顶栏不再显示 fps 之类的性能文本 —— 平时都是满帧，没必要占位。
- 配色参考 feralui.dev：近黑底 + 暖陶土 `#c9704a` + 青蓝 `#8bd1d8` + 奶油 `#f9efb9`，
  背景带一层很淡的暖/冷双向径向光，不至于死板。
- **字体全站统一一套无衬线**（`Segoe UI Variable Text → Segoe UI → system-ui → … sans-serif`），
  数字用 `font-variant-numeric: tabular-nums` 对齐；**没有任何等宽/衬线字族**，
  不会掉进 Courier New 那种带衬线的兜底。

### 对齐规则：以文字为准，图标让路

面板里所有横向关系都建立在「一条文字基准线」上，而不是控件外框：

| 元素 | 位置 | 做法 |
|---|---|---|
| 参数标签 / 折叠组标题 / 预设文字 | 都从 `x = 199px`（气泡内 20px）开始 | 文字列只有一个原点 |
| 折叠箭头、预设彩点 | 挂在基准线左侧的 14px 沟槽里 | `position:absolute; left:-12/-9px`，**不参与排版**，不推挤文字 |
| 数值列 | 定宽 88px，数字右对齐栏 54px + 单位栏 30px | 有没有单位都占位，所以 `振幅 %` 和 `波数 个/周` 的数字左右缘完全重合 |
| 行高 | 每行 58px（折叠开关行 34px） | 所有控件统一 30px 高，行距节奏均匀 |

## 为什么不用 SVG 滤镜 / WebGL

| 方案 | 形状真由噪声生成 | 时间连续 | 参数独立可调 | 能导出矢量 |
|---|---|---|---|---|
| `feTurbulence` + `feDisplacementMap` | ✗ 只把已渲染像素推歪 | ✗ 换 seed 会突跳 | ✗ 频率/振幅强耦合 | ✗ |
| WebGL 片元 SDF 场 | ✓ | ✓ | ✓ | ✗ 只能截图 |
| **周长参数化 + 周期噪声位移** | ✓ | ✓ | ✓ | ✓ |

决定性理由：轮廓是一条**真实闭合曲线**，所以预览、SVG `path`、CSS `polygon()`、PNG 四者同源。

## 预设

内置预设写在 `src/wavy.js` 的 `presets` 数组里（改这里 = 改所有人的默认值），
用户自己「＋ 存为预设」的存 `localStorage`（`stylekit:presets:v3`）。

`tomotachi` 是内置列表里的第一个，同时是**空白启动时的默认样式**：
`#ffc100` 黄、圆角 40、振幅 4%、波数 5、单层噪声（octaves 1 / gain 0.1）、
`speed 0`（噪声不演化）但 `drift 0.5`（波形沿边缘缓慢巡航）。

> 同名去重：如果 `localStorage` 里有和内置同名的用户预设（比如你自己存的 `tomotachi`），
> 界面上只显示内置那一份，不会出现两个 `tomotachi`。
## 基础形状

底形不是写死的圆角矩形，而是先由 `src/shape.js` 生成一条带外法线的闭合折线，再交给噪声沿法线位移。

形状选择是**一排图标按钮**（不是下拉框）：矩形 / 椭圆 / 多边形 / 星形 / SVG 路径，选中的那个高亮成陶土色。

**多边形和 SVG 有二级菜单**（`#shape-sub` 里的可折叠块，标题右侧带实时摘要，收起也能看到当前状态）：

| 形状 | 二级菜单 | 摘要 |
|---|---|---|
| 多边形 | `边数` | `6 边` |
| 星形 | `边数`、`星形内径` | `9 边 · 内径 30%` |
| SVG 路径 | 导入按钮 + 状态 | `未导入` / `24 段` |
| 矩形、椭圆 | 无 | — |

SVG 菜单在**还没导入时自动展开**，导入成功后摘要变成段数，可收起；切换形状时菜单跟着换，不会残留。

| 形状 | 说明 |
|---|---|
| **矩形** | `radius` 控制圆角，`radius = min(w,h)/2` 就是胶囊 |
| **椭圆** | 按 `w × h` 拉伸，随宽高比自动变形 |
| **多边形** | `sides` 3~24 边；`radius` 是**顶角圆角**（真正的圆弧倒角，不是简单插值） |
| **星形** | `sides` = 角数，`spike` = 内径/外径比（0.15 尖细 → 0.9 接近多边） |
| **SVG 路径** | 读文件里**第一个**可测轮廓（`path/polygon/polyline/rect/circle/ellipse/line`），采样后 RDP 简化成一条 `d` |

`shapeRot` 只转底形不转整体（整体旋转仍是把手/`rot`）。所有形状共用同一套噪声、颜色、描边、投影参数。

### SVG 导入怎么做的

1. 用 **HTML 解析器**读文件（XML 解析器遇到缺 `xmlns` 的 SVG 会得到无命名空间元素，`getTotalLength` 就没了）
2. 拿第一个图形元素，`getTotalLength()` + `getPointAtLength()` 直接借浏览器把 `<rect rx>`、贝塞尔全部拍平
3. **按跳变切段**：多子路径（比如「头 + 身」）会被连成直线，靠相邻采样点距离突然变大切开，只留最长那段
4. **RDP 简化**（容差 = 对角线 0.4%），锚点从上千个压到几十个，`d` 通常 < 300 字符，能安全塞进 URL

### 尖角怎么不变刺

噪声沿法线位移，在尖角处天生容易自交 —— 表现为「火苗 / 细刺」。三层防护：

1. **法线平滑**：法线场做 4 遍 ±3 邻域加权平均（顶点处法线 180° 翻转会被平滑掉）
2. **曲率限幅**：用 ±4 采样点估局部曲率半径 `R`，位移量夹到 `0.9R` 以内（尖点 R 很小 → 位移被压住）
3. **空间平滑**：按 `R` 决定模糊半径对**位移场**做两遍邻域平均 —— 尖点两侧在参数上离得远、空间上挨得近，各自独立位移就会把尖点夹成细刺；共享同一段位移后，尖端整体平移

实测：五角星在 `amp 4%` 下连续 5 个时刻，尖端 2.5px 内的横向宽度分别是 7.3 / 5.7 / 4.5 / 5.6 / 5.0 px，**没有出现 < 1px 的细刺**。
## 核心算法

1. **圆角矩形按弧长参数化**，每点带外法线；法线在「直边→圆角」处天然连续，位移后不出折角。
2. **噪声对周长周期化**：把 `t∈[0,1)` 映到噪声空间里的一个圆
   `u = cos2πt·R, v = sin2πt·R`（`R = waves/2π`）。绕一圈回到原点 ⇒ 闭合处严格无缝。
3. **第三维就是时间**：`noise3(u, v, speed·t)`，形变连续、可暂停；相位里加 `drift·t`，波峰沿周长巡航。
4. **域扭曲**：`t += warp·noise(圆(1.3t))`，仍对 `t` 周期，破不了闭合。
5. **振幅口径**：`amp` 是 `min(w,h)` 的百分比；fbm 归一化后集中在 0 附近，过一层 `tanh(1.35v)`
   软压缩，让整条边都吃到位移，峰值不越界。
6. **性能**：单帧重建 300~2600 点 `Path2D` 并 `fill()` 一次；实测单帧绘制 3.6ms（4 块同屏）。

## 参数

| 组 | 参数 |
|---|---|
| 核心 | `shape` 形状 · `amp` 振幅 · `waves` 波数 · `mode` fbm/ridged/billow/sharp · `fill` 填充色 |
| 形状与尺寸 | `w` `h` `radius` 圆角 · `sides` 边数 · `spike` 星形内径 · `shapeRot` 形状自转 · `svg` 导入 · `x` `y` 位置 · `rot` 旋转 |
| 噪声细节 | `octaves` 层数 · `lacunarity` 频率倍率 · `gain` 振幅衰减 · `warp` 域扭曲 · `seed` 种子 |
| 动画 | `drift` 波漂移 · `speed` 形变速度 |
| 描边 | `stroke` `strokeW` `strokeColor` |
| 投影 | `shadow` `shadowBlur` `shadowY` `shadowAlpha` `shadowColor` |

每个数字参数都是**滑块 + 数字框**双通道：滑块是手感，数字框可键入、支持 ↑↓ 步进（步长 = 参数 step）、
越界实时夹到 `min/max`、失焦回填格式化值（并去掉无意义尾零：`9.0 → 9`、`12.50 → 12.5`）。

> 开关（描边 / 投影）有个坑：开关行**不能**注册到「按条件显隐」的表里，否则一关掉就把自己也隐藏了，
> 再也点不回来。只有它的从属行（描边宽/描边色、模糊/偏移/不透明度/投影色）才按 `when` 隐藏。
> 从属行包括 `range` 和 `color` 两种控件，都要注册（早期只注册了 `range`，导致关掉投影后「投影色」还在）。

> 数字框的实现有个坑：**键入时绝不能在 `input` 事件里回写 `input.value`**。
> 一写就会重置光标、把 `12.` 这种中间态用 `toFixed` 抹掉，表现就是「键按得下去但数字不动」。
> 现在的规则是：键入只更新模型 + 滑块，输入框文本保持用户原样；格式化只发生在失焦 / 回车。
> 外部同步（预设、随机、拖动）也会跳过当前获得焦点的输入框。

## 导出（左下角按钮）

| 按钮 | 产物 | 范围 |
|---|---|---|
| `HTML` | 单击**下载** `.html` 单文件组件；Shift+单击复制代码 | 整场 |
| `CSS` | 5 帧 `clip-path` 关键帧，纯 CSS 无 JS | 选中变体 |
| `SVG` | 每块 `<g transform>` + `path` + 独立投影 | 整场 |
| `JSON` | 完整场景数据 | 整场 |
| `WebM` | 点一下开始录、再点一下结束并下载（最长 20 秒，30fps VP9） | 整场 |

### WebM 录制的两个坑

1. **`captureStream` 的 canvas 必须挂在 DOM 里**。 detached 的 canvas 在 Chrome 里不会被合成，
   `MediaRecorder` 拿到的是空 blob（第一次实现就是这样，文件 0 字节）。做法：把录制画布放到
   `position:fixed; left:-10000px`，用户看不见但仍在合成树里。录完再 `remove()`。
2. **视频格式基本不支持 alpha**。直接把透明画布录下来会得到黑底。所以先读
   `getComputedStyle(document.body).backgroundColor` 把当前底色烤进每一帧，波形本身照常绘制。

帧率 30fps、码率按分辨率算并封顶 16Mbps，1:1 分辨率（2× 会让软件 VP9 编码掉帧）。
实测 2 秒 ≈ 340 KB，`ffprobe` 验证：`vp9 / 1424×805 / 30fps / matroska,webm`；
抽第 0 秒和第 1.5 秒两帧对比，形状确实在形变（不是静帧）。
导出是**按需生成**：点按钮时才跑一次导出（HTML 要读 `dist/wavy-edge.js` 内联），
平时不占渲染开销，所以画布永远满帧。

场景状态实时写进 URL hash（只存与默认值不同的参数），复制链接即可还原。

## 验收

```powershell
node tools/check.js                         # 振幅线性 / 时间连续 / 闭合性
node tools/gen-exports.mjs tools/shots 1    # 生成导出物
node tools/shot.mjs http://127.0.0.1:8791/index.html out.png 2500
```

- 几何：`amp` 10/20/30/40% → 实测最大位移 12.2/24.5/36.7/48.9px（线性）；相邻帧最大点位移 0.51px；
  首尾点距 1.77px ≈ 相邻点距 2.00px（闭合无缝）。
- 把手：角拖 520×340 → 640×440 且中心不动；旋转拖出 45.0°；`Shift` 等比后 w/h 比 2.00。
- 气泡：始终落在视口内（1440×900 下 top 295 / bottom 884），不压图层面板、不压左下导出按钮。
